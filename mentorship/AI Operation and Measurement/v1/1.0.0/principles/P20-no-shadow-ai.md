# P20 · No Shadow AI: every agent has a catalog entry and a named owner

**Statement.** No agent runs without a named Agent Owner, a declared risk tier, its four facets (Runtime · Trigger · Surface · Role) and an entry in the Agent Catalog. Target: 100% of AI assets inventoried; agents operating outside IT oversight: none.

**Why.** Autonomous agents outside oversight introduce financial (token maxing), regulatory and security liabilities. Governance, promotion, cost attribution and audit all key off the catalog entry; an unregistered agent cannot be throttled, traced or defended.

**Rules.**
- No catalog entry, no run. The Agent Catalog Steward owns the registry; each entry records Agent Owner, four facets, risk tier, current maturity level, version, status, persona and autonomy budget.
- Each agent has its own identity and scoped credentials, enforced against its declared Surface, so it can touch only what it was registered for. No agent has standing access to production.
- Ungoverned AI asset found → remediated within 30 days (Tier 4 SLA).
- Catalog coverage is a Tier 4 key result (100%) and a Stage 1 exit criterion.
- Every PQC rolls up to a registered agent and its maturity level; every escalation routes to the named accountable human.
- Retired agents are archived with their prompts, evals, telemetry and audit trail, not deleted.
- The catalog is also the single storefront for approved agents and skills (see P17).

**Primitives governed.** Agent Catalog entry, Agent Owner, Four facets, Risk tier, Agent identity, Agent Catalog Steward.
